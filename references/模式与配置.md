# 输入和人物模式

日常脚本与JSON字段示例见examples/job.json。保持终审文案，text用于口播，headline/cards/takeaway用于画面；covers的hook/data/question为三个封面标题，不直接把正文整段塞进卡片。

## 静态头像 static

默认。导入个人素材库后可用--avatar A/B/C；自定义照片由portable.py configure --photo配置。源照片先保留景别，程序在输出时裁圆。无模型积分，不提供动作。

## 本地近似嘴型 mouth

使用--avatar-mode mouth --avatar A/B/C。目前只支持随个人包导入的三张已校准母图及对应rig，不适用于任意新照片。通过Whisper词时间和拼音驱动简化嘴型、眨眼，复用对齐词时间，不能冒充神经口型或真实手势。新照片须另行校准嘴与眼睛坐标。

## 姿势图 poses

使用--avatar-mode poses --avatar B。导入个人包提供的B三姿势图后按幕切换，场景可填pose_id=neutral/explain/emphasis。A/C没有姿势库，缺失时报错，不自动换衣服或下载模型。它是静态图片替换。

## 现有口播视频 video

使用--avatar-video <视频路径>。默认保留原音轨。多幕必须先转写，并让每幕video_start/video_end从0起连续覆盖原视频；不要猜时间或给视频重新克隆声音。该模式不进行默认语速校准，以保持口型与原声对应。

## 已有录音

配置voice.mode=recorded，每幕audio为本机真实录音片段。提供caption_cues或保留alignment本地识别。该模式默认不变速。没有VoiceStudio后台的机器也可用这条路线；仍需字体、浏览器、FFmpeg和字幕环境。

## 检查与输出

由.runtime/runtime.json找到Python后执行：

`<Python> -X utf8 scripts/workflow.py doctor --profile profiles/personal.json`

实际生成：

`<Python> -X utf8 scripts/workflow.py run --job <job.json> --profile profiles/personal.json`

A/B/C参数仅在library.json和对应图片实际存在时使用。单条人物视频不得自动循环冒充当前文案口型。修改配音语速后字幕和分镜以新音频为准。缓存只缓存声音，不表示每次渲染都不耗时。

MOSS没有精细情绪控制，默认平均语速校准约4.15字/秒，调整幅度0.8–1.2倍，保留原音频与报告。它不消除所有句内节奏差异，也不新增情绪。自动转写能发现部分漏读和时间问题，不能证明音色相似。

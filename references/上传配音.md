# 上传配音直接驱动

VoiceStudio是可选依赖，不是这套Skill运行的必要前提。上传已录好的MP3/WAV配音时使用recorded路线；不克隆音色、不调用TTS、不进行默认语速校准。客户自己录制，或使用自己已有工具配好的声音，均可作为成品配音输入。

首次选择页新增“配音方式”：默认推荐上传配音，可切换为只发文案、本人克隆。选择保存在profiles/appearance.json的audio_source字段，值为recorded或clone。install按此设置决定是否下载VoiceStudio，也可通过--audio-mode显式覆盖。现有已配置MOSS的用户不会在没有新选择时被自动切换。

录音路线：`<Python> scripts/portable.py install --audio-mode recorded`；然后`<Python> scripts/portable.py configure --audio-mode recorded --photo <本人照片>`。配置不访问VoiceStudio。原有配置要改时仍需用户明确要求并加--replace备份，不随意覆盖原来的声音档案。

## 有录音也有文案

Agent编排每幕的headline/cards/text；text必须与录音实际内容一致。运行：

`<运行时Python> scripts/workflow.py run --job <job.json> --profile profiles/personal.json --audio <完整配音.mp3>`

也可在job顶层填audio_source。单幕默认用整段录音，多幕必须填每幕audio_start/audio_end，按实际时间从0连续覆盖到录音结束。程序验证覆盖范围；不能只把同一个完整音频复制到每一幕。录音时长决定视频时长，字幕按录音对齐。即使profile仍是克隆模式，显式传入--audio也会跳过TTS。

## 只有录音，没有文案

先使用本地字幕环境转写：

`<运行时Python> scripts/transcribe_recording.py --audio <录音> --output <转写.json>`

得到实际词/段时间后，Agent按内容组织分镜、标题和卡片。转写是候选，需核对识别错误，不能把重新润色、与实际录音不符的新稿当作口播。分镜覆盖完整音频，字幕与原声一致。

## 人物选择

- static：圆形静态头像，最快。
- poses：用预先准备好的姿势图随分镜换图；不是连续身体动作。
- mouth：用录音和识别时间驱动已校准头像的本地近似嘴型、眨眼；不提供真实手势，不冒充精确神经口型。
- video：用户提供同文案的现成口播视频，默认保留它自己的原音轨。不要同时传另一段配音，避免音画冲突。

最终仍输出竖版MP4与自动封面。上传原声只省掉TTS生成，不省掉字幕识别和视频渲染。系统仍需Whisper、FFmpeg、Node和浏览器环境；Skill负责调度这些工具。

已有克隆配置但本条使用上传录音时，环境检查加 `doctor --profile profiles/personal.json --recorded`，不要求TTS服务在线。

# 1.3 图文笔记与产品分析风格

## 输出形式

视频继续走原有workflow.py run；小红书图文走workflow.py notes或notes.py。纯图文直接导出1080×1440（3:4，默认）PNG/JPG，也可9:16；不调用TTS、Whisper、FFmpeg或HyperFrames视频渲染。浏览器按已嵌入字体排版截图，保留每页HTML供修改。

用户只需对Agent说“把下面这段话做成小红书图文笔记”。Agent保留原意，提炼标题与卡片，决定页数和版式，生成notes job再执行，不要求用户手写JSON。当前没有内置的独立LLM写作API；内容编排由调用本Skill的Agent完成。

## 风格

保留原八种预设，新增brief-light（产品分析·浅色）与brief-dark（产品分析·深色）。来自本轮参考图的设计语言：超大黑体标题、蓝色强调、直角卡片、图片对照、流程链路、来源脚注。两者也可用于视频与自动封面。不是复制参考图的产品、价格、品牌或未经验证的官方结论。

## 输入结构

示例见examples/notes.json。顶层title/theme/series/header/pages，caption/tags可选；page_numbers默认不显示，明确要求页码时设true，不显示FIG。每页可单独theme切换深浅。header品牌与栏目沿用已有配置，也可由单条任务覆盖。

每页headline必填，最多48字，显示时去标点（保留必要数值意义），使用思源黑体Bold700，不描边。正文保留标点。每页支持：

- cover：lead、hero、hero_note、cards、callout。
- comparison：cards对比卡，最多4张，每张title/body；优先短文案。
- flow：rows最多2条，每条label/steps（2–4步）/note，配callout。
- stat：stat.value/unit/label；不能编造数字，需说明原稿/来源与统计口径。
- image：images最多2张，path为本地PNG/JPG/WebP，caption/fit可选；配cards解释。图片相对路径按job文件目录解析，复制到任务media后排版，不抓取不明远程图片。
- takeaway：结论、行动卡或提问，配lead/cards/callout。

所有版式都可提供takeaway和sources（最多3条）。来源只填用户给出的可核查材料或明确“依据用户文案整理”，不能假装做过官方核验。资料不足时不凭空补价格、数据、产品照片或证据。没有图片时使用文字/流程版式，不伪造照片。

## 命令

纯图文安装：`<Python> scripts/portable.py install --output-mode notes`。只准备Node依赖与浏览器，不安装VoiceStudio、Whisper/PyTorch，不要求FFmpeg；已有视频配置和Python环境保留。

生成：`<Python> scripts/workflow.py notes --job <notes.json> [--profile profiles/personal.json] [--style brief-light]`。

也可直接执行`<Python> scripts/notes.py --job <notes.json> --output <新的空目录>`。已有输出不会覆盖，需新目录。显式提供任务主题可直接生成，不替用户修改长期默认；长期默认仍通过初始化保存。

输出：每页PNG/JPG、每页HTML、图文预览.html、发布文案.md、manifest.json、check.json及status.json。自动检查图片解码、嵌入字体等待、文本溢出、正文与来源重叠；放不下时报错拆页，不偷偷截断内容。

## 初始化

初始化增加video/notes选择，纯图文隐藏配音选项。风格库从8变为10。菜单1根据选择安装对应环境；纯图文配置无需声音或头像，保留已有私人配置，不把文字克隆变成强制前提。

# 1.1 风格与个性化页眉

## 风格清单

| 对话名称 | theme / --style | 视觉 |
|---|---|---|
| 当前浅灰黑红 | studio-paper | 白色立体倾斜卡片，红色强调；默认 |
| 早期简洁卡片 | paper | 第一版演示的圆角列表卡片 |
| 深蓝金色 | navy | 早期深色截图的蓝底、金色重点 |
| 暖纸杂志 | editorial-ink | 暖纸、细线、分栏、大面积留白 |
| 瑞士克莱因蓝 | swiss-blue | 直角纯色网格、蓝色强调 |
| 瑞士柠檬黄 | swiss-yellow | 直角纯色网格、黄色强调 |
| 瑞士柠檬绿 | swiss-green | 直角纯色网格、绿色强调 |
| 瑞士安全橙 | swiss-orange | 直角纯色网格、橙色强调 |

八个预设属于五类视觉体系，其中四套瑞士配色共用同一套版式。杂志/瑞士选项参考归藏Skill的设计体系，针对竖版口播重新实现；不是归藏PPT模板的逐页移植，也不依赖其WebGL或网络字体。所有预设保留用户指定的思源黑体Bold真实700标题和无标点显示标题，因此不会使用归藏原模板的衬线或极细大字规则。来源：https://github.com/op7418/guizang-ppt-skill 。

主题优先级：命令行--style > 单条job.theme > 初始化保存的appearance.theme > profile.theme > studio-paper。正式生成前必须完成首次选择。缺失时兼容旧配置；未知名称会在配音前报错，不静默选另一个。

## 页眉字段

顶层header可写入单条job或profiles/personal.json；单条任务覆盖默认配置。只覆盖提供的字段，保留其他设置。Agent根据用户对话填入，不要求用户手写JSON。

```json
{
  "theme": "swiss-blue",
  "header": {
    "brand": "张老师的运营笔记",
    "tagline": "门店经营 每期一招",
    "section_prefix": "",
    "section_label": "获客与成交",
    "show_number": false,
    "number_start": 1,
    "number_pad": 2,
    "visible": true,
    "section_visible": true
  }
}
```

- brand：最上面左侧品牌/账号名；最多24字。为空不显示文字。
- tagline：最上面右侧栏目名，并用于封面页脚；最多24字。为空可去掉。
- section_prefix：原“FIG.”的位置，最多12字，可写“运营课”“第”或留空。
- section_label：编号右边的文字，最多24字。省略时按每幕label变化；显式空字符串则不显示栏目文字。封面也继承它。
- show_number：是否显示幕编号；false隐藏编号。前缀仍可显示，若前缀也不想要则设section_prefix为空。
- number_start：首幕编号，0–9999整数；每幕递增。number_pad：最少位数1–4。
- visible：是否显示顶部品牌栏；false隐藏品牌栏及封面品牌栏。
- section_visible：是否显示FIG这一行；false隐藏整个编号栏目行，视频与封面均生效。

两行可分别隐藏，隐藏后留白位置保持稳定。header所有文字按纯文本处理，不支持HTML。每幕scene.header可只覆盖section_prefix/section_label/show_number/section_visible；不能在单幕改变全局品牌与起始编号。

封面跟随主题、品牌和页眉设置，仍输出三种标题方向、9:16与3:4两种比例。浅色黄/绿强调区域自动用黑字，避免白字对比不足。

## 使用例句

- “用暖纸杂志风，B头像，文案如下……”
- “这条用瑞士克莱因蓝，页眉写校长运营笔记，FIG改成运营课，从03开始。”
- “以后默认用当前浅灰黑红，顶部写张老师，右边写门店经营，不显示FIG那一行。”（Agent先读取本机profile，再仅更新theme/header字段，保留声音和路径。）
- “刚才那条改深蓝金色，不重新配音。”

## 命令行

列出风格：`<运行时Python> scripts/workflow.py styles`

新任务：`<运行时Python> scripts/workflow.py run --job <job.json> --profile profiles/personal.json --style swiss-blue`

只换画面：`<运行时Python> scripts/workflow.py restyle --source <原任务目录> --style editorial-ink`

同时换页眉时加 `--header-json <header.json>`；文件内容直接是header对象本身（不再套一层header）。不指定--style则沿用原风格。加--no-render可只生成页面和封面供预览。

restyle复制原任务media到新的jobs目录，沿用配音、人物媒体和字幕时间，不调用VoiceStudio/ASR，也不推进头像轮换；每次生成新目录。它复用音频，仍需时间渲染新画面。修改口播文案不能用restyle。原任务的估算字幕/音色/口型等限制仍然存在，restyle不会替它们做质量认证。


## 首次风格选择

运行scripts/portable.py init自动打开本机浏览器，展示八种风格对比图。首次不预选；用户必须选择后点击保存。选择保存在profiles/appearance.json，随后正式生成沿用。可再次运行init更换默认。默认不显示FIG与幕编号。
